# 像素深渊 (Pixel Abyss)

像素风 Roguelite 地牢探索游戏。使用 Godot 4.3+ 开发。

## 玩法

- 从安全屋出发，进入随机生成的地牢
- 击杀怪物获得装备掉落（白/绿/蓝/紫/橙五级稀有度）
- 每层末尾有 Boss，击败后进入下一层
- 死亡回到安全屋，用灵魂币购买永久强化

## 操作

| 按键 | 动作 |
|------|------|
| WASD / 方向键 | 移动 |
| J / 鼠标左键 | 攻击 |
| K / 空格 | 闪避翻滚 |
| I / Tab | 打开背包 |
| E | 交互 |
| ESC | 暂停 |

## 运行

1. 安装 [Godot 4.3+](https://godotengine.org/download/)
2. 用 Godot 打开 `project.godot`
3. 按 F5 运行游戏

## 技术

- 引擎: Godot 4.3+ (GDScript)
- 分辨率: 320x180 (整数缩放至 1280x720)
- 地牢生成: BSP 二叉空间分割算法
- 目标平台: macOS / Windows (未来支持移动端)
