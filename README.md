# 像素深渊 (Pixel Abyss)

像素风 Roguelite 地牢探索游戏，支持 1-4 人局域网/云房间联机。使用 Godot 4.6+ 开发。

## 玩法

- 选择 4 种职业之一（战士/法师/游侠/刺客），各有独特攻击和技能
- 进入随机生成的地牢，击杀怪物获得经验和装备（白/绿/蓝/紫/橙五级稀有度）
- 升级获得技能点，过关后在商店界面自由分配天赋
- 4 大地牢主题循环（石窟深渊 → 地下森林 → 熔岩炼狱 → 亡灵殿堂），每 3 层一个主题，主题间地板/墙壁色调、房间装饰物、飘浮粒子完全不同
- 每层末尾有 Boss（小 Boss / 大 Boss 轮替），击败后进入过层商店
- 背包支持装备对比（悬停显示属性差异）和一键批量出售
- 支持 1-4 人多人联机协作闯关

## 运行

### 从源码运行
1. 安装 [Godot 4.6+](https://godotengine.org/download/)
2. 用 Godot 打开 `project.godot`
3. 按 F5 运行游戏

### 打包版本
- **macOS**: 解压 `build/mac/像素深渊.zip`，双击 `.app` 运行
- **Windows**: 将 `build/windows/` 下的 `.exe` 和 `.pck` 放同一目录，双击 `.exe`

> macOS 首次打开未签名应用：右键 → 打开，或在"系统偏好设置 → 安全性"中允许

## 多人联机

### 局域网模式
1. 主机玩家点击"创建局域网房间"
2. 其他玩家输入主机 IP 加入

### 云房间模式
1. 部署云房间服务到你的服务器（见 `server/README.md`）
2. 主机玩家点击"创建云房间"，获得 6 位房间码
3. 其他玩家通过"浏览房间"或输入房间码加入

## 项目结构

```
├── scripts/
│   ├── player/          # 玩家控制器、属性、弹道
│   ├── enemies/         # 敌人 AI（9种：史莱姆/骷髅/哥布林/眼球怪/蘑菇/食人植物 + 6种Boss）
│   ├── skills/          # 技能系统（主动技能 + 被动天赋）
│   ├── network/         # 联机（NetworkManager + CloudRoomAPI）
│   ├── dungeon/         # 地牢生成、氛围系统（主题染色/装饰/粒子）
│   ├── items/           # 装备、战利品、商店
│   ├── managers/        # 全局管理器（存档、音频、游戏状态）
│   ├── ui/              # UI 界面（大厅、HUD、背包对比/批量出售、技能选择）
│   └── story/           # 对话系统
├── scenes/              # Godot 场景文件
├── assets/              # 美术资源（Kenney Tiny Dungeon + Tiny Creatures）
├── data/                # JSON 数据表（敌人、物品、剧情）
├── docs/                # 素材词典等文档
├── tools/               # 脚本工具（导出、精灵生成）
├── server/              # 云房间后端（FastAPI + PostgreSQL）
└── build/               # 打包输出（.gitignore 已排除）
```

## 技术栈

- **引擎**: Godot 4.6+ (GDScript)
- **分辨率**: 640×360 (canvas_items 缩放至 1280×720)
- **地牢生成**: BSP 二叉空间分割算法 + 确定性种子
- **联机架构**: ENet P2P，主机权威模型（敌人 AI、伤害由主机控制）
- **云服务**: Python FastAPI + PostgreSQL（房间发现服务）
- **目标平台**: macOS / Windows
